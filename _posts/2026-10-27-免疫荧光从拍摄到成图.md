## 实验操作
1. 实验方法
	1. 猕猴睾丸石蜡切片经脱蜡和抗原修复后，用磷酸盐缓冲液（PBS）洗涤并进行封闭。随后，切片分别与兔源多克隆抗 CADM1（Invitrogen/Thermo Fisher Scientific，PA5-102512）、抗 claudin-11（Invitrogen/Thermo Fisher Scientific，36-4500）或抗 ZO-1（Invitrogen/Thermo Fisher Scientific，61-7300）一抗孵育过夜，一抗均按 1:200 稀释。PBS 洗涤后，加入 Alexa Fluor 647 标记的山羊抗兔 IgG H&L 二抗（Abcam，ab150079，1:200）孵育。再次用 PBS 洗涤后，使用按 1:20 稀释的 DAPI 染液进行细胞核复染。最后，经 PBS 洗涤，使用即用型 Fluoromount-G 封片剂（SouthernBiotech，0100-01）封片。

		        1. 主要调整图像的亮度偏移，让参考暗区接近黑色

		        3. 设置完ROI后点击拍照即可
		    10. 切换物镜
		        1. 去除黑平衡模式
		        2. 切换40X，调节细准焦，重新设置曝光时间（多通道均要调节），目标与之前一致，记录当前通道设置
		        3. 拍照，黑平衡拍照，取消黑平衡
		    11. 切换视野
		        1. 切回20X，调回之前的20X通道设置，调焦
		        2. 切换到目标视野后直接拍照
		        3. 重复操作，紧接9
		    12. 检查文件夹，确认所有的文件都拍好了
			13. 关闭实时观察，切成10X，拉出载物台，卸下玻片

			2. 定量
				1. 每个组别只有3个视野，进行student T检验，发现ZO-1未出现显著差异，但是图中可以看到结果较好
				2. 本次定量指标为中央生精小管内的红色信号面积比例，即 Red signal area（%）。以手动勾画的中央生精小管轮廓作为分析区域（ROI），包含管腔。将 ROI 内达到红色信号阈值的像素数除以 ROI 总像素数，再乘以100，得到每个视野的红色信号面积百分比。
				3. 定量使用原始红通道像素值，范围为0–255。CADM1、CLDN11和ZO-1的信号下限分别为71、21和51，上限均为255。同一抗体的所有图像使用一致的阈值。绘图代码读取定量结果中的 `signal_area_percent`，作为后续计算的原始数据。
				4. 首先计算每个生物学样本的均值。同一编号的不同视野属于同一个生物学样本，因此先对这些视野的面积百分比求平均。例如，CADM1的19085样本包含两个视野，平均值为38.533%；19363样本包含一个视野，其样本值为20.774%。随后以生物学样本为单位计算组均值，使每个样本具有相同权重。
				5. 每个抗体分别进行归一化，以Blank组两个生物学样本均值的平均值作为共同分母。例如，CADM1的归一化分母为（38.533%＋20.774%）÷2＝29.654%。该抗体所有样本均值及各视野的原始面积百分比均除以这一分母，得到相对于Blank组的倍数，即fold。
				6. 柱高表示组内两个生物学样本归一化结果的平均值，因此Blank组柱高为1；误差线表示两个生物学样本归一化结果的标准误（SEM）。每个黑色实心圆点代表一个视野的归一化结果，每组显示3个视野。由于各样本包含的视野数不同，柱高可能与3个视野散点的直接算术平均值不同。

.restart_copy_checked <- function(from, to) {
    if (dir.exists(from)) {
        if (file.exists(to) && !dir.exists(to)) 
            stop("Target is not a directory: ", to)
        rel_files <- list.files(from, recursive = TRUE, all.files = TRUE, full.names = FALSE, no.. = TRUE)
        if (dir.exists(to)) {
            extra <- setdiff(list.files(to, recursive = TRUE, all.files = TRUE, no.. = TRUE), rel_files)
            if (length(extra)) 
                stop("Unexpected files in existing companion directory: ", to)
        }
        folders <- unique(c("", list.dirs(from, recursive = TRUE, full.names = FALSE)))
        for (folder in folders) {
            target <- file.path(to, folder)
            if (!dir.exists(target) && !dir.create(target, recursive = TRUE)) 
                stop("Cannot create: ", target)
        }
        for (rel in rel_files) {
            .restart_copy_checked(file.path(from, rel), file.path(to, rel))
        }
        return(invisible(TRUE))
    }
    if (!file.exists(from)) 
        stop("Source file missing: ", from)
    if (dir.exists(to)) 
        stop("Target is a directory: ", to)
    if (file.exists(to)) {
        if (!identical(unname(tools::md5sum(from)), unname(tools::md5sum(to)))) {
            stop("Existing target has different contents; not overwritten: ", to)
        }
        return(invisible(TRUE))
    }
    if (!dir.exists(dirname(to)) && !dir.create(dirname(to), recursive = TRUE)) {
        stop("Cannot create target parent directory: ", dirname(to))
    }
    if (!file.copy(from, to, overwrite = FALSE, copy.date = TRUE)) 
        stop("Copy failed: ", from)
    if (!identical(unname(tools::md5sum(from)), unname(tools::md5sum(to)))) {
        stop("Copy verification failed: ", to)
    }
    invisible(TRUE)
}
